使用方法

三步，开始双语收听。

从安装到阅读，不到一分钟。

播放节目

在 Chrome 中打开 podcasts.apple.com，播放任意一期节目。

打开阅读器

点击工具栏中的插件图标，选择「打开阅读器」。转录与翻译自动就绪。

对齐一次

听到转录第一句时，点击「对齐到此句」。之后便逐句同步。

现在就开始。

免费、开源，源代码托管于 GitHub。

下载插件 (.zip) 所有版本

安装步骤

  1. 下载并解压 ZIP 文件。
  2. 在 Chrome 地址栏打开 chrome://extensions/。
  3. 打开右上角的「开发者模式」。
  4. 点击「加载已解压的扩展程序」，选择解压后的插件文件夹。
  5. 打开 Apple Podcasts 播放节目，点击插件图标即可使用。
